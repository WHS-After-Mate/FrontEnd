# WHS After Mate 서비스 기획안

## 서비스 개요

피부과·에스테틱 시술 후 사후관리를 체계적으로 도와주는 모바일 앱.

시술 받고 나면 "얼마나 지나야 세안해도 되지?", "오늘 뭐 바르지?" 같은 소소한 질문들이 생기는데, 매번 병원에 전화하기 애매하다. 그 틈을 채워주는 서비스.

## 타겟 사용자

- 피부과/에스테틱에서 시술을 받는 고객
- 시술 후 관리 방법을 매번 까먹는 사람
- 다음에 뭘 받으면 좋을지 고민하는 사람

## 핵심 기능

### 1. 홈

로그인하면 가장 먼저 보는 화면.

- 최근 시술 이력 요약
- 오늘의 사후관리 카드 (경과일 기반)
- 이용권 잔여 현황
- AI 추천 관리 미리보기

### 2. My Care

내 시술 이력을 한 눈에 관리.

- **캘린더 뷰**: 시술 날짜별 이력 조회
- **히스토리 뷰**: 시술 종류별 필터링, 카드형 목록
- 시술 상세 정보 (시술명, 날짜, 사업장, 경과일)

### 3. AI 가이드

시술 경과일에 맞는 맞춤 사후관리 안내.

- 최근 받은 시술 기준 자동 가이드 생성
- 경과일별 단계적 안내 (당일 → 3일 → 7일 → ...)
- 주의사항, 추천 행동, 피해야 할 것 정리
- AI Q&A 챗봇으로 궁금한 점 바로 질문

### 4. AI 관리 추천

다음에 받으면 좋을 관리를 추천.

- 고객의 관심 목표(관심 태그) 기반 매칭
- 최근 시술 이력 분석해서 보완 시술 제안
- 추천 근거 표시 (왜 이 시술인지)
- 사업장 상담 연결

### 5. 설정

- 프로필 관리 (이름, 이메일, 생년월일, 관심 목표 수정)
- 비밀번호 변경
- 알림 설정 (사후관리 알림 / 마케팅 알림)
- 로그아웃

## 사용자 흐름

```
앱 실행 → 스플래시 → 온보딩(최초) → 로그인/회원가입
                                         ↓
                              홈 ─── My Care ─── AI 가이드 ─── 설정
                               │
                               └── AI 관리 추천
                               └── AI 챗봇
```

## 회원가입 프로세스

1단계: 본인 확인
- 병원에서 부여받은 환자번호 + 이름 + 생년월일 + 전화번호로 서버 대조
- 기존 환자 DB와 매칭되어야 가입 가능 (아무나 가입 X)

2단계: 계정 생성
- 이메일, 비밀번호 설정
- 관심 목표 선택 (중복 가능)

## 알림 체계

| 종류 | 설명 | 기본값 |
|------|------|--------|
| 사후관리 알림 | 경과일에 맞는 케어 안내 푸시 | ON |
| 마케팅 알림 | 이벤트, 할인 등 프로모션 | ON |

- 알림 설정은 사용자 계정에 귀속 (기기 종속 X)
- FCM 기반 푸시

## 관심 목표 태그 (10개)

리프팅·탄력 / 모공·피지 관리 / 보습·장벽 강화 / 색소침착 개선 / 얼굴 윤곽·볼륨 / 제모 / 두피 관리 / 바디라인·체형 관리 / 붓기 케어 / 컨디션·대사 관리

## 기술 스택

| 구분 | 기술 |
|------|------|
| 프론트엔드 | Flutter (Dart) |
| 백엔드 | (별도 레포) |
| 인증 | JWT (Access + Refresh Token) |
| 푸시 | FCM |
| AI | LLM 기반 사후관리 안내 + Q&A 챗봇 |

## 연동 사업장

- 3개 사업장 연동 (피부과/에스테틱)
- 사업장별 시술 카탈로그 관리
- 카카오톡 채널 상담 연결

## 차별점

- 병원 환자번호 기반 가입 → 검증된 사용자만 이용
- AI가 경과일에 맞춰 알아서 안내해줌 (사용자가 찾아볼 필요 없음)
- 시술 이력 기반 다음 관리 추천 → 재방문 유도
