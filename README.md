# WHS After Mate Frontend

WHS After Mate의 **사용자용 모바일 앱 프론트엔드 프로젝트**입니다.

피부·미용 시술 후 사용자가 자신의 관리 내역을 확인하고, 시술별 사후관리 정보를 보다 쉽게 확인할 수 있도록 제작한 서비스입니다.

본 프로젝트는 실제 의료 서비스 운영을 위한 상용 앱이 아니라, **서비스 흐름과 핵심 기능을 시연하기 위해 제작한 데모 및 프로토타입 프로젝트**입니다.

## 주요 기능

* 온보딩 및 로그인
* 홈 화면

  * 최근 관리 내역 확인
  * 현재 필요한 사후관리 정보 확인
* My Care

  * 캘린더 기반 관리 일정 확인
  * 관리 및 시술 이력 조회
* 관리 상세

  * 시술 정보
  * 시술 부위
  * 경과일에 따른 사후관리 안내
* AI 사후관리 가이드

  * 시술 종류와 현재 경과일을 기반으로 한 안내
  * 사용자 질문에 대한 사후관리 정보 제공
* 이용권 관리

  * 보유 이용권 및 사용 횟수 확인
  * 이용권 만료일 확인
* 클리닉별 관리 정보 확인

## 프로젝트 목적

WHS After Mate는 시술 이후 고객이 겪는 정보 탐색의 불편함을 줄이고,
**개인의 시술 이력과 현재 경과 시점에 맞는 사후관리 정보를 한곳에서 제공하는 것**을 목표로 합니다.

관리자 웹에서 등록된 고객 및 관리 데이터를 앱과 연동하여 사용자가 자신의 관리 내역을 확인하는 서비스 구조를 구현했습니다.

실제 서비스 적용 시에는 의료기관에서 사용 중인 CRM, EMR 또는 고객관리 시스템과의 연동을 고려합니다.
